# 💬 Лёгкий мессенджер на Python

Общий чат для небольшой группы (по умолчанию — 3 человека).
Flask + SQLite, веб-интерфейс, работает в браузере на телефоне и ПК.

## Файлы
- `app.py` — сервер (логика, БД, API)
- `templates/login.html` — страница входа
- `templates/chat.html` — страница чата
- `requirements.txt` — зависимости
- `Procfile` — команда запуска для хостинга

## Запуск локально
```bash
pip install -r requirements.txt
python app.py
```
Открой http://127.0.0.1:5000

## Пользователи
Логины и пароли заданы в `app.py` в словаре `USERS`. Поменяй на свои:
```python
USERS = {
    "anna":  "anna123",
    "boris": "boris123",
    "vera":  "vera123",
}
```

## Перед публикацией обязательно
Задай свой секретный ключ через переменную окружения `SECRET_KEY`
(используется для шифрования сессий).
