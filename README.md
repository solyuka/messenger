# 💬 Мессенджер на Python (с регистрацией)

Общий чат с регистрацией. Сообщения и пользователи хранятся в базе данных.
Flask + база (SQLite локально / PostgreSQL на хостинге).

## Возможности
- Регистрация новых пользователей (страница `/register`)
- Вход / выход
- Пароли хранятся в зашифрованном виде (хэш)
- История сообщений сохраняется в базе данных
- **Аватарки**: клик по фото в шапке → выбрать картинку (сжимается до 200px)
- **Передача файлов P2P**: файлы НЕ хранятся на сервере, идут напрямую
  с устройства отправителя получателю (WebRTC). Отправитель должен быть онлайн.
- **Автоочистка**: сообщения старше 7 дней удаляются автоматически
- Работает в браузере на телефоне и ПК

## Как работает передача файлов
1. Отправитель выбирает файл (📎) — файл остаётся в памяти его браузера,
   в чат уходит только карточка с именем/размером.
2. Получатель кликает по карточке → устанавливается прямое соединение
   (WebRTC), файл передаётся напрямую и скачивается.
3. Сервер участвует только в "знакомстве" браузеров (signaling), сам файл
   через него НЕ проходит и нигде не сохраняется.

⚠️ Ограничение: чтобы скачать файл, вкладка отправителя должна быть открыта.

## Файлы
- `app.py` — сервер
- `templates/login.html` — вход
- `templates/register.html` — регистрация
- `templates/chat.html` — чат
- `requirements.txt` — зависимости
- `Procfile` — команда запуска для хостинга

## Запуск локально
```bash
pip install -r requirements.txt
python app.py
```
Открой http://127.0.0.1:5000 → зарегистрируйся → пользуйся.
Локально используется файл `chat.db` (SQLite), настраивать ничего не нужно.

## База данных
- **Локально:** если переменной `DATABASE_URL` нет — используется SQLite (`chat.db`).
- **На хостинге:** если задана `DATABASE_URL` (PostgreSQL) — используется она,
  и данные сохраняются навсегда.

## Переменные окружения на хостинге
- `SECRET_KEY` — любая длинная случайная строка (для сессий)
- `DATABASE_URL` — адрес PostgreSQL (Render подставляет автоматически при привязке БД)
